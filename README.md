# SE Initial Commit 2026

Невеликий локальний вебзастосунок для символічної посвяти першокурсників
спеціальності «Інженерія програмного забезпечення».

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Vite покаже локальну адресу, зазвичай:

```text
http://localhost:5173
```

Для показу на проекторі відкрийте браузер у fullscreen.

## Список студентів

Редагується у:

```text
src/data/students.json
```

Формат:

```json
[
  {
    "id": 1,
    "name": "Олексій Петренко"
  }
]
```

## Керування

- Оберіть студента зі списку.
- `Enter` — запустити посвяту / commit.
- Після фінального екрану `Enter` — перейти до наступного студента.
- `Esc` — повернутися до списку.
- Статус уже посвячених студентів зберігається у localStorage браузера.

Фізична кнопка може емулювати звичайну клавішу Enter.
